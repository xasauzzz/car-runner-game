# Car Runner Game

Небольшая игра на Python и Pygame: вы управляете машиной, объезжаете другие машины и набираете очки.

## Как запустить игру

1. Зайдите в репозиторий:
   https://github.com/xasauzzz/car-runner-game
2. Нажмите кнопку **Code → Download ZIP**
3. Распакуйте архив себе на компьютер.
4. Откройте распакованную папку.
5. В адресной строке проводника введите `cmd` и нажмите Enter — откроется консоль в этой папке.
6. Установите зависимости:

   ```bash
   pip install -r requirements.txt
Запускайте игру - python mashinki.py
